# Netflix Exploratory Data Analysis (EDA)

## Project Overview
This project explores the Netflix Titles dataset using Python. The goal is to understand the content available on Netflix through data analysis and visualization.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (VS Code)

## Dataset
Netflix Titles Dataset (CSV)

## Analysis Performed
- Movies vs TV Shows
- Top 10 Countries
- Content Release Trend
- Top Genres
- Ratings Distribution
- Movie Duration Distribution
- TV Show Seasons Distribution
- Missing Values Analysis

## Key Insights
- Movies are more than TV Shows.
- United States has the highest number of titles.
- India ranks second.
- Netflix content increased rapidly after 2015.
- TV-MA is the most common rating.
- Most movies are around 90–100 minutes long.
- Most TV Shows have only one season.
